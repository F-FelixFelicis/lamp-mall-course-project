## 导入和恢复

全新数据库在 apps/api 下运行 `python -m app.seed_demo`，会生成账号、认证、目录与报价。已有旧演示数据运行 `python -m app.demo_catalog`，无需重建账号或数据库。只允许默认本地 SQLite 和原演示账号；先验证所有素材，再用 SQLite backup 生成 `.local/before-photo-catalog-时间.db`。商品、图片、报价均通过真实 M2 API 完成创建和审核；仅来源信息写入 SKU 既有 extra_attributes 字段，不新增迁移。

升级后旧 DEMO-001-A 至 DEMO-003-A 只在所属商家、名称、品牌、示意图描述均匹配时下架；不删除旧商品、上传文件、报价或审核记录。重复运行跳过既有有效报价，保留手动下架状态；碰到编号冲突或人工修改的状态会停止，不覆盖。中途中断后可重跑；不要同时开启多个导入进程。恢复时先停止后端，保留当前数据库副本，再将备份作为运行数据库；上传文件没有删除。

照片已随仓库提供，导入无需外网。若素材意外缺失，可以从项目根目录运行 `python tools/fetch_catalog_photos.py`，仅下载清单列出的固定许可素材；已有文件不覆盖。
