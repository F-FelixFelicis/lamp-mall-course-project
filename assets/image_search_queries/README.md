# 以图搜图查询图片候选集

采集日期：2026-10-25。包含 15 张与现有 20 张商品目录照片来源 ID 不重复的实拍图片，初步覆盖台灯、吊灯、落地灯、壁灯和吸顶/顶装灯具，每类 3 张。文件由 `tools/fetch_image_search_queries.py` 根据逐项核查的 Pexels 照片页下载；重复执行会保留现有文件。逐图的摄影师、来源页面、下载地址、许可、尺寸与 SHA-256 在 `manifest.json` 中。

图片遵循 [Pexels License](https://www.pexels.com/license/)：可用于网站/应用等用途，但不得暗示摄影师或品牌为项目背书，不得将原图作为图片商品转售，也不得将它们汇集为竞争性图库。项目仅将照片用作课程检索测试候选；照片许可不因进入仓库而变更。若对外发布成独立数据集，应重新核对各照片页与平台条款。图片中的灯具并非本商城真实在售商品，不能用来证明商品品牌、规格或价格。

这些图片**尚不是可计算 Recall@5 / Precision@5 的正式评测集**。`preliminary_category` 只根据照片页和人工浏览标注了粗类别；同类不等于“视觉相关”，也不能把该字段直接当成相关性真值。部分图包含房间背景、多个光源、遮挡或较小目标，适合作为难例，但需逐张复核。

后续评测步骤：

1. 固定一版商品图库、SKU 与可售状态；剔除同源或近重复图片，保留查询图与商品图的来源分离记录。
2. 至少两名组员独立判断每张查询图相对各候选 SKU 的外形、灯型与风格相关性；先写清“相关”的判定标准，再记录分歧及最终裁定。
3. 将查询图、标注、数据划分与随机种子冻结。开发/调参不得使用最终测试标注。
4. 在同一图库与环境下运行简单基线及主方法，保存 Top-K 结果、延迟、索引版本和失败样例。只有完成这些步骤后才能报告实际 Recall@5、Precision@5 或 P95 数值。

这批图不是商品上架素材，也不会由商品导入脚本写入商城数据库。M4 已接入视觉检索和颜色基线，但这些查询候选仍待人工相关性标注。冻结清单、盲标注页面和正式评测入口见 [评测目录](../image_search_benchmark/README.md)。
